# Cloud Cost Analyzer

A Python-based Cloud Cost Analyzer that processes monthly cloud billing CSV files,
combines them into a yearly dataset, analyzes costs, identifies unused resources,
and visualizes spending trends.

## Features
- Reads multiple monthly billing CSV files
- Combines data into a single yearly DataFrame
- Calculates total and service-wise cloud costs
- Identifies unused or underutilized resources
- Visualizes monthly and yearly cost trends

## Tech Stack
- Python
- Pandas
- Matplotlib
